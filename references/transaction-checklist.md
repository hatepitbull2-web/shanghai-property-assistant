# 购房材料与流程核对清单

这是一份经纪人准备访谈的清单。是否需要、具体格式和时效，以办理时上海官方及经办机构要求为准，不能表示客户已经取得资格或贷款批准。

1. 资格核验：购房区域、家庭现有住房、户籍或居住情况、适用社保/个税条件，关联官方政策日期。仅请求摘要，不在开源示例保存证件信息。
2. 身份与家庭证明：核对办理机构所需身份证明、户籍/居住及婚姻相关证明；涉及共有或委托的另核实授权材料。
3. 资金与贷款：确认实际可动用首付、旧房出售回款、公积金/商业贷款方案、银行要求的收入及流水材料、利率和期限。
4. 新房：核对预售/销售资格、对应批次、认购规则、入围与摇号安排、房号、备案价格、交付标准、合同约定与资金支付节点。
5. 二手房：核对产权主体及共有人、抵押查封、租约与交付、附属车位、税费与佣金承担、资金监管及过户条件。
6. 合同和交房：把已核实结论与剩余问题分开，记录承诺的书面依据、材料负责方和办理节点。

政策、资格、税费或贷款条件未知时，报告保留待核实项。测算中的3%等输入只代表用户或演示假设，不代表银行报价。
