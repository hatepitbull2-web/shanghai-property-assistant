# 客户需求采集

经纪人先用自然对话获取以下信息；已有答案直接复用。每项记为硬条件、偏好或待确认。

| 类别 | 要问的内容 | 用途 |
|---|---|---|
| 购买动机 | 首置、置换、改善、养老、自住期限；为什么现在买 | 排定取舍顺序 |
| 资金 | 总价上限、可动用首付、月供舒适上限、税费与装修备用金、是否依赖卖旧房 | 预算及资金节奏 |
| 地点 | 可接受区域、办公/日常目的地、交通方式、通勤上限 | 区域筛选与路线核实 |
| 居住人数 | 常住人数、老人儿童需求、独立卧室、卫生间、电梯无障碍 | 户型功能 |
| 产品 | 新房/二手房/都可、建筑面积、房间数、楼层、朝向、阳台、装修 | 房源硬条件 |
| 时间 | 最迟入住、是否接受期房、是否需过渡租住 | 交付筛选 |
| 配套 | 学校需求、医疗、商业、公园、停车，按重要性排序 | 比较依据；学校须核实官方口径 |
| 不接受 | 连廊、噪声、低楼层、特定朝向、长交付周期等 | 排除与现场检查 |
| 决策 | 谁一起决策、已看过哪些盘、喜欢/否决原因 | 避免重复推荐 |
| 资格待核 | 户籍类别、购房区域、已有房屋套数、社保/个税连续月份、家庭情况 | 仅列政策核验事项；不收证件号码 |

不要把所有信息设为必填。未提供通勤目的地时先做房源初筛，通勤记待核。新房和二手房可共用需求表，但二手房还需核实单套产权、抵押、租约、税费承担及真实成交记录。

引擎当前结构化硬筛字段：budget_max_wan、area_min_sqm、area_max_sqm、bedrooms_min，以及其帮助文档支持的地区条件。其余需求由宿主结合有来源资料处理，并保留未覆盖项；不得暗示已执行未实现的筛选条件。
